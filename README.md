# JavaScript Testing Practice with Jest

A collection of pure JavaScript utility functions thoroughly tested using **Jest** and configured with **Babel** for seamless ES module support.

## 🚀 Features & Functions

The project includes the following functions located in `function_4.js`:

1. **`capitalize(str)`**: Takes a string and returns it with the first character capitalized.
2. **`reverseString(str)`**: Takes a string and returns it reversed.
3. **`calculator`**: An object containing basic arithmetic operations (`add`, `subtract`, `divide`, `multiply`).
4. **`analyzeArray(arr)`**: Takes an array of numbers and returns an object with properties: `average`, `min`, `max`, and `length`.
5. **`caesarCipher(str, num)`**: Takes a string and a shift factor, returning a Caesar cipher encrypted string while preserving case and non-alphabetic characters.

## 📦 Installation & Setup

1. Clone the repository and navigate to the project directory.
2. Install the dependencies:
   ```bash
   npm install
   ```

## 🧪 Running Tests

To run the test suite and see the coverage of all implemented functions:
